The Engine

3-Way Reconciliation Pipeline

ExceptionOS doesn't just do A to B. It bridges the entire financial lifecycle.

📓

🎯 7 Exception Classifications

Automatically flags matched, amount mismatches (fees), missing, duplicates, timing issues, date mismatches, and unknowns.

🧠 Heuristic Matching

If IDs are missing, ExceptionOS falls back to advanced matching based on amounts, currencies, and smart date windows.

🛡️ Zero Rounding Errors

Built entirely on Python's Decimal. Never loses a cent to floating-point drift.

Data Engine

Synthetic Financial Data Generation

Need to test your systems? ExceptionOS ships with a built-in deterministic data generator.

  • Generates realistic Ledger, Gateway, and Bank CSVs.
  • Injects 8 distinct edge cases (refunds, fees, delays).
  • Outputs a ground_truth.json file for ML training.
  • Creates strict train and test dataset splits.
$ exceptionos-generate --train 500 --test 200
